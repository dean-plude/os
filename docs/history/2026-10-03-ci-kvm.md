## Test VMs run under KVM in CI

The self-tests, the graphics suite and the nightly app corpus ran QEMU under
TCG (software emulation).  GitHub-hosted Linux runners expose `/dev/kvm`, so
`tools/novarun.py` now passes `-accel kvm` when the device is readable and
writable and `-accel tcg` otherwise (`NOVARUN_ACCEL=tcg|kvm` forces one), and
CI and the nightly run add a udev rule that opens `/dev/kvm` to the runner
user before the VMs start.  The CPU model and the SMP counts are unchanged.

Job times (Actions runs of this change) are recorded in the pull request
description.
