NovaOS 0.1.0 is the first release of NovaOS: a from-scratch x86-64
operating system that runs native Windows programs.  Their own machine
code runs directly on the CPU; NovaOS supplies the NT system calls, the
Win32 API, the loader, the desktop and the drivers they expect.  64-bit
programs run natively and 32-bit ones through NovaOS's own WoW64.

This ISO passed every CI suite before it was published: the core,
network and device self-tests (including starting from this ISO) and the
OpenGL and Direct3D tests.

## What runs

7-Zip, Git, Notepad++, Firefox, KeePassXC, Inkscape, SumatraPDF,
WinMerge, VLC, Audacity, ffmpeg, Neovim, the Java, .NET, Node.js and
Python runtimes, `.msi` and NSIS installers, and OpenGL, Vulkan and
Direct3D 8 to 11 programs through Mesa and DXVK from the App Store.
[docs/compatibility.md]({blob}/docs/compatibility.md) lists every
program checked and how well it runs.

## Starting it

Check the download first: `sha256sum -c nova.iso.sha256` on Linux,
`shasum -a 256 -c nova.iso.sha256` on a Mac.

- **In QEMU** (Linux, macOS, Windows through WSL2): boot `nova.iso` on a
  q35 machine with UEFI firmware (OVMF) and 2 GB of memory; the
  [user guide]({blob}/docs/user-guide.md#trying-it-in-a-virtual-machine)
  has the command lines.
- **On a PC** with UEFI and Secure Boot off: write `nova.iso` to a USB
  stick (`dd`, Rufus in DD mode or balenaEtcher) and start from it.
- Started from the ISO, NovaOS runs live and offers **Install NovaOS**,
  which installs it on a disk.  The first start of the installed system
  asks for your name, time zone, keyboard layout and display resolution.

The [user guide]({blob}/docs/user-guide.md) covers the desktop, the App
Store, files, network and sound; [docs/building.md]({blob}/docs/building.md)
builds the same image from source.

## Updates

An installed NovaOS 0.1.0 updates itself from the newest release: the App
Store's **Updates** page, or `update` in the Terminal, reads this
release's `novaos-update.txt` and installs a newer kernel and boot loader,
going back to the old ones if the new kernel does not reach the desktop
([docs/updates.md]({blob}/docs/updates.md)).

## Known limits

- NovaOS is developed and tested in QEMU.  The reference PC, a Lenovo
  ThinkPad T14 Gen 4 (Intel), has drivers for its network card, audio,
  microphones, touchpad, NVMe disk, sleep and battery, checked against
  modelled devices; [docs/hardware.md]({blob}/docs/hardware.md) says what
  has been checked on the machine itself.  Other PCs are untested.
- 3D runs on the CPU (llvmpipe, lavapipe) except in QEMU's virtio-gpu
  with Venus; there is no driver for a real GPU yet.
- No Wi-Fi, Bluetooth or Secure Boot.
- Games whose anti-cheat makes its own system calls, such as Roblox's
  Hyperion, stop at start
  ([docs/compatibility.md]({blob}/docs/compatibility.md#roblox-and-anti-cheat)).
- Update channel files are not signed yet; they are checked by size,
  SHA-256 and version only.
