| `nstest` | The NetSurf browser (graphics suite): it writes a page with an SVG image, an `<svg>` element written inline in the HTML, a list a script builds and a box a script changes, and starts NetSurf on it; the test sees the SVG's filled and outlined shapes, the inline SVG's shapes at the size its `width`, `height` and `viewBox` give, and the three list items on the screen, clicks the box (its script changes its style attribute and adds text after the page was laid out) and sees the page redrawn with the changed box and the images and list still there, then closes NetSurf, which must exit normally |
